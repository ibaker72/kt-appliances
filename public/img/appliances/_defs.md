# Appliance artwork

These SVGs are **placeholders**. They render when an inventory record has no uploaded
photograph, so a newly added appliance never shows a broken or empty image box.

They are intentionally neutral vector renderings — not photographs and not stock imagery.
Replace them by uploading real warehouse photos through `/admin`; any listing with at least
one uploaded image uses that image instead and never falls back here.

All artwork uses one shared visual system:

- `viewBox="0 0 800 600"` (4:3), so grid cells never shift when a real 4:3 photo replaces one
- soft studio-gray background gradient with a contact shadow under the unit
- stainless and white body gradients, `#9aa0a8` panel lines
